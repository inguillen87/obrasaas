The Apache-2.0 license is included as biometric-model-license.txt.
Immutable revisions and SHA-256 checksums are enforced in _biometric_core.py.
No remote model code is executed. No identity images are uploaded to Hugging Face.

This implementation uses the upstream 0..255 BGR input and live class 1.
The third-party ONNX model card's 0..1 input and live class 0 are inconsistent
with upstream inference. ONNX logits were compared with the pinned original
PyTorch weights, using a deterministic random input, before this integration.

Outputs are uncalibrated advisory signals. A static-image passive score does
not prove life, document authenticity or legal identity. Approval remains a
separate human decision in the canonical participant workflow.
